# NEXORA Logistics — strona internetowa

Responsywna, statyczna strona w języku polskim, przygotowana do publikacji przez GitHub Pages.

## Pliki
- `index.html` — treść i struktura strony
- `style.css` — wygląd strony i wersja mobilna
- `script.js` — menu mobilne i formularz otwierający aplikację pocztową

## Publikacja na GitHub Pages
1. Zaloguj się na https://github.com
2. Kliknij **+** → **New repository**.
3. Nazwij repozytorium `nexora-logistics` i wybierz **Public**.
4. Utwórz repozytorium.
5. Kliknij **Add file** → **Upload files**.
6. Przeciągnij do repozytorium trzy pliki: `index.html`, `style.css`, `script.js` (README też może zostać).
7. Kliknij **Commit changes**.
8. Wejdź w **Settings** → **Pages**.
9. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
10. Wybierz branch `main` i folder `/ (root)`, a następnie kliknij **Save**.
11. Po zakończeniu publikacji adres pojawi się w sekcji Pages. Zwykle ma postać `https://TWOJ_LOGIN.github.io/nexora-logistics/`.

## Przed publicznym uruchomieniem
- Potwierdź, że możesz używać nazwy NEXORA Logistics.
- Uzupełnij politykę prywatności, jeśli uruchomisz narzędzia zbierające dane.
- Formularz obecnie nie przechowuje danych — przygotowuje wiadomość w domyślnej aplikacji pocztowej.
- Sprawdź prawny zakres usług, formę działalności i ewentualne wymogi licencyjne. Nie dodawaj niezweryfikowanych danych rejestrowych ani deklaracji o licencjach.
- Zdjęcia zewnętrzne nie są wymagane; grafiki na stronie są zbudowane z CSS/SVG. Czcionki pobierane są z Google Fonts; jeśli chcesz uniknąć zewnętrznych żądań, usuń linki Google Fonts z `index.html` i użyj czcionek systemowych w `style.css`.
